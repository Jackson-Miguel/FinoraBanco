# Finora

Uma aplicação bancária desenvolvida para simular
operações financeiras de maneira simples e intuitiva.

## Sobre o projeto

Apresentação do objetivo e da proposta da aplicação.

## Funcionalidades

- Depósito de valores
- Saque de valores
- Consulta de saldo
- Extrato de movimentações

## Tecnologias utilizadas

- TypeScript
- JavaScript
- HTML5
- SCSS
